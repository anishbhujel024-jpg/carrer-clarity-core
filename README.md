# 🎯 Career Clarity Core Engine (v5.5)
### *The Ultimate Tactical Intelligence Terminal for Modern Career Strategy*

**Career Clarity Core** is a high-fidelity professional strategy dashboard built for the 2025 landscape. It leverages the cutting-edge capabilities of **Google Gemini 3** and **OSINT (Open Source Intelligence)** grounding to transform static professional dossiers into dynamic, verifiable, and executable tactical roadmaps.

---

## 🤖 Neural Intelligence Stack

This engine utilizes a multi-modal AI architecture designed for maximum accuracy and real-time relevance:

- **Primary Reasoning Engine:** `gemini-2.5-flash-lite` handles deep profile auditing and synaptic roadmap synthesis on the Gemini API free tier.
- **Verification Protocol:** **Google Search Grounding** is active across all modules. The AI doesn't just "guess"—it queries the live internet to verify 2025 salary benchmarks, hiring trends, and technical documentation.
- **Structured Synthesis:** Fully driven by `@google/genai` using strict JSON schemas to ensure the UI remains a direct representation of neural outputs.
- **Curation Logic:** A Zero-Tolerance link verification system ensures every curated video resource (YouTube, MIT OCW, Coursera) is live and precisely matches the user's identified skill gaps.

## 🛠 Installation & Deployment

### Local Protocol
```bash
# Clone the repository
git clone https://github.com/your-username/career-clarity-core.git

# Install dependencies
npm install

# Environment Configuration
# Create a .env file and inject your credential:
# VITE_GEMINI_API_KEY=your_gemini_api_key

# Initialize Terminal
npm run dev
```

### Technical Requirements
- **Node.js:** 18.x or higher
- **Browser:** Modern Chromium/WebKit for optimal animation rendering.
- **API Access:** Google Gemini API key with Search Grounding enabled. In Vite, browser-exposed environment variables must use the `VITE_` prefix, so configure `VITE_GEMINI_API_KEY` locally, in Codespaces secrets, or in your hosting provider's environment settings.
